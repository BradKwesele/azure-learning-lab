\# Phase 1: Development Environment \& Git Workflow



\## Overview



This phase covers the foundational setup for Azure Infrastructure as Code development, including tool installation, repository structure, and Git branching strategy.



\## What's Covered



\- \*\*Environment Setup:\*\* Azure CLI, VS Code with Bicep extension, Git configuration

\- \*\*Project Structure:\*\* Repository organization for scalable IaC development

\- \*\*Version Control:\*\* Git branching workflow (feature branches, pull requests, merge strategy)

\- \*\*Azure Basics:\*\* Core Azure platform concepts and initial Bicep introduction

\- \*\*Azure Account Configuration:\*\* Subscription setup and CLI authentication
